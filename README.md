# Vyrra Personal AI

My own take on a J.A.R.V.I.S.-style voice assistant, powered by **Vyrra** — a local AI assistant with its own personality and long-term memory.

## Status

🚧 Early setup. Nothing runnable yet.

## Inspiration

This project draws on [adewaskar/jarvis](https://github.com/adewaskar/jarvis) (MIT License), a browser voice assistant with an Iron Man holographic interface. A local copy is kept under `reference/` for study and is not tracked in this repository. Any code adapted from it will keep its original MIT copyright notice.
